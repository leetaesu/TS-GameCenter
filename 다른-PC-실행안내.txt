TS 게임센터 — 다른 컴퓨터에서 실행하기
========================================

준비물
1. 이 폴더 전체
2. 새 컴퓨터에 설치된 Node.js LTS: https://nodejs.org/

가장 쉬운 실행 방법
1. ZIP 압축을 풉니다.
2. ts-game-center 폴더 안의 "실행.bat"를 더블클릭합니다.
3. Windows 방화벽 창이 나오면 "개인 네트워크"를 허용합니다.
4. 잠시 뒤 PC 브라우저에서 http://localhost:5007 이 열립니다.
5. 휴대폰은 검은 서버 창에 표시되는 http://192.168.x.x:5007 주소로 접속합니다.

중요
- PC와 휴대폰은 같은 Wi-Fi 또는 같은 공유기에 연결해야 합니다.
- 게임하는 동안 검은 서버 창을 닫으면 안 됩니다.
- 서버를 끝내려면 검은 창에서 Ctrl+C를 누릅니다.
- EADDRINUSE가 나오면 이미 게임센터가 실행 중입니다. 기존 서버 창을 닫고 다시 실행하세요.
- 카페·회사·게스트 Wi-Fi는 기기 간 연결을 막을 수 있습니다.

명령어로 실행하려면
1. 이 폴더 빈 곳에서 Shift+마우스 오른쪽 버튼을 누릅니다.
2. "PowerShell 창 열기" 또는 "터미널에서 열기"를 선택합니다.
3. 다음 명령을 입력합니다.

npm start

별도의 npm install은 필요하지 않습니다.
