# TS 게임센터

같은 Wi-Fi에 연결된 2~4명이 각자의 휴대폰 또는 PC 브라우저로 즐기는 로컬 멀티플레이 오락실입니다. 다이노 런은 혼자 연습할 수도 있습니다.

현재 플레이 가능한 게임:

- 과일폭풍 종치기: 같은 과일의 합이 5가 되면 먼저 종을 치는 카드 게임
- 네온 다이노 런: 1인 연습 또는 2~4인 점프·숙이기 생존 레이스

## 실행

저장소 루트에서:

~~~powershell
npm run play:ts-game-center
~~~

또는 이 폴더에서:

~~~powershell
npm start
~~~

호스트 PC에서는 `http://localhost:5007`을 엽니다. 서버를 켜면 터미널에 `http://192.168.x.x:5007` 형태의 휴대폰 접속 주소도 표시됩니다.

게임이 끝난 뒤 서버 터미널에서 `Ctrl+C`를 누르면 안전하게 종료됩니다. 휴대폰이 접속해 있는 동안에는 호스트 PC와 터미널을 계속 켜두세요. 5007 포트가 이미 사용 중이면 PowerShell에서 `$env:PORT=5008; npm start`처럼 다른 포트를 지정할 수 있습니다.

## 같이 플레이하기

1. 모든 기기를 같은 Wi-Fi에 연결합니다.
2. 메인 화면에서 게임을 고르고 `게임 시작`을 누른 뒤 방을 만듭니다.
3. 대기실의 초대 주소 또는 4자리 방 코드를 친구에게 전달합니다.
4. 친구는 주소를 열거나 메인 화면에서 코드를 입력해 입장합니다.
5. 모두 준비 완료한 뒤 방장이 게임을 시작합니다.

연결되지 않으면 Windows 방화벽에서 Node.js의 개인 네트워크 통신이 허용됐는지 확인하세요. 게스트 Wi-Fi처럼 기기 간 통신을 차단하는 네트워크에서는 동작하지 않을 수 있습니다.

대기실 QR 코드는 외부 사이트에 접속하지 않고 브라우저에서 직접 생성됩니다. PC에 유선·Wi-Fi 주소가 여러 개 있으면 `휴대폰 접속망`에서 휴대폰과 같은 공유기의 주소를 선택하세요. `localhost`는 휴대폰용 초대 주소로 사용하지 않습니다.

## 조작

- 종치기: `F` 카드 뒤집기, `Space` 종 치기
- 다이노 런: `Space` 또는 `↑` 점프, `↓` 숙이기
- 모바일: 화면 하단의 큰 조작 버튼 사용. 다이노 숙이기는 버튼을 누르는 동안 유지됩니다.

## 과일폭풍 종치기 규칙

- 2~4명이 56장을 나눠 받고 차례대로 카드 한 장을 공개합니다.
- 공개된 카드 중 같은 과일의 합이 **정확히 5**일 때 누구나 종을 칠 수 있습니다.
- 정답이면 종을 가장 먼저 친 사람이 공개 더미 전부를 가져가고 다음 차례를 시작합니다.
- 오답이면 종을 친 사람이 다른 참가자에게 카드 한 장씩 줍니다.
- 빠른 로컬 플레이를 위해 덱이 0장이 된 참가자를 즉시 탈락 처리하며, 마지막으로 덱이 남은 한 명이 승리합니다.
- 같은 공개 카드 상태에서는 서버에 가장 먼저 도착한 종 입력 하나만 인정합니다.

클라이언트 화면은 결과를 임의로 정하지 않습니다. 카드 이동, 종 정답, 승자와 재대결은 모두 호스트 PC의 서버가 판정합니다.

연결이 끊긴 참가자의 차례는 건너뛰며, 모두 잠시 끊겼다가 한 명이 먼저 복귀하면 그 참가자부터 차례를 이어갑니다. 대기실로 돌아가거나 재대결이 실제로 시작될 때는 복귀하지 않은 참가자의 빈 자리를 정리합니다.

## 테스트

~~~powershell
npm test
~~~

자동 검사는 2·3·4개의 WebSocket 브라우저 역할을 만들어 입장, 준비, 시작, 56장 보존, 동시 종 최초 1명 판정, 오래된 입력 차단, 방장 이탈과 승계, 토큰 재접속, 재대결을 확인합니다. 다이노 런도 1·2·3·4인 흐름과 동일 최종 순위를 검사합니다.

## 실제 휴대폰 최종 확인표

실제 기기 검증은 호스트 PC와 휴대폰이 준비된 현장에서 진행해야 합니다.

- PC에서 서버를 실행한 동안에만 휴대폰이 접속할 수 있습니다.
- 휴대폰 2~4대를 같은 일반 Wi-Fi에 연결합니다.
- QR로 입장하고 각 기기에 서로 다른 닉네임이 보이는지 확인합니다.
- 종치기에서 2·3·4인 방을 각각 시작하고 카드 뒤집기, 정답 종, 오답 종, 동시 종을 확인합니다.
- 종치기에서 한 기기를 새로고침한 뒤 같은 카드 수와 자리로 복귀하는지 확인합니다.
- 다이노 런에서는 각 기기에 서로 다른 공룡 색이 보이는지 확인합니다.
- 모든 기기에서 점프, 숙이기, 체력 감소와 최종 순위가 같은지 확인합니다.
- 한 기기의 Wi-Fi를 잠시 끄거나 새로고침한 뒤 같은 자리로 돌아오는지 확인합니다.
- 방장 연결을 끊었을 때 다른 참가자가 방장을 이어받는지 확인합니다.
- 결과 화면에서 대기실로 돌아가 재대결을 시작합니다.

접속이 안 되면 다음 순서로 확인합니다.

1. 휴대폰과 PC가 같은 공유기인지 확인
2. 대기실에서 올바른 Wi-Fi/이더넷 주소 선택
3. Windows 방화벽의 Node.js `개인 네트워크` 허용
4. 게스트 Wi-Fi 또는 공유기 `AP isolation` 해제
5. 5007 포트가 사용 중이면 다른 프로그램을 종료하거나 `PORT` 변경

카페·학교·회사 Wi-Fi는 기기 간 통신을 막을 수 있습니다. 현재 버전은 인터넷 공개 서버가 없으므로 서버 비용은 들지 않지만 다른 장소에서는 접속할 수 없습니다. 호스트 PC가 서버이므로 PC를 끄면 게임도 종료됩니다.
